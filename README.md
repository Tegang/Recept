# 🍲 Recept
En modern och responsiv webbapp för att administrera, söka och laga mat-recept. Byggd med Google Apps Script, Google Sheets och en PWA-vänlig frontend.

### ✨ Funktioner
- 🔍 **Smart sökning** bland rätter, ingredienser och taggar.
- 🎙️ **Kockläge & Röstassistent** (läser stegen högt och styrs med röstkommandon).
- ⏱️ **Inbyggda timers** med ljudlarm direkt i recepten.
- 🔗 **Länk-recept** för att smidigt spara favoriter från externa sajter (Coop, Arla, Tasteline m.fl.).
- 📱 **Mobilanpassad** och kan installeras som app på telefonen (PWA).
